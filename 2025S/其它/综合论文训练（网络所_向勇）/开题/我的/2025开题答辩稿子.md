# 毕设开题稿

## 研究背景和意义

在操作系统发展中，外设起到非常重要的作用。
而针对一种特定的外设，设计并实现一个对上层操作系统独立的硬件驱动模块，供操作系统开发人员直接调用，能够帮助在其开发的操作系统中快速实现对硬件的控制。
从用户进程角度来讲，用户进程使用操作系统提供的系统调用，通过对外设进行读写，实现对外设的操作。
读写系统调用执行模型主要有阻塞和非阻塞、同步和异步等执行模型。
非阻塞希望调用该系统调用时无论结果立刻返回，从而不会强制停止当前进程的执行，而异步则不强制代码执行的先后顺序，后续代码不强制依赖于当前读写操作的完成。
因而异步 I/O 很适合对于外设操作的 I/O 密集型场景。
以下列出了一些异步 I/O 的实现方式（多线程系统接口,语言支持，语言支持，语言支持，支持协程和异步），主要分无栈协程和多线程实现两种方式。
这其中用无栈协程实现的异步 I/O 相比于传统的多线程并发设计，省去了操作系统上下文切换和栈空间开辟和切换的开销，因而能够极大提升程序的运行性能。

## 研究概况

目前串口驱动主要是使用 C 语言进行编写。
而 Rust 作为一门新兴的编程语言，由于拥有高于 C 语言的内存安全性、更现代的语法和等同于 C 语言的性能，因此适合于系统编程。
也因此使用 Rust 语言编写操作系统组件逐渐成为趋势。比如 Linux 已经对其众多的硬件驱动模块进行了 Rust 改造，一定地说明了操作系统开发者对 Rust 的认同。
由于 Rust 优秀的内存安全和并发处理能力，也使得其成为驱动开发的理想选择。

## 研究选题

我的研究选题是**Rust 异步串口驱动模块设计与实现**，也就是为一些外设编写基于 Rust 异步逻辑的、能够真机运行的驱动模块。

## 研究目标和内容

研究目标是利用 Rust 的异步支持，并参考一些已有的异步运行实现，首先在模拟器上进而在开发板上实现能够跨操作系统和文件系统的异步串口驱动。预期结果希望优于传统 C 实现。

主要内容
首先在模拟器上复现前人实现过的 Rust 异步串口驱动模块对于 Alien OS 的适配，然后成功移植到星光 2 开发板上。
在这之后实现 SD 卡闪存块设备的异步驱动并上板，目标是成功运行一个文件系统（考虑到工作量，可能跑一些简单的文件系统 FAT, LittleFS）并通过相应测例集。 

为了体现用 Rust 写异步逻辑的优越性，需要对实现的模块进行测试和分析。
设想是对实现的模块进行压力测试，以及是否能够兼容不同的系统，输入/输出的延迟测试，长时间压力测试下是否能不出错，以及一些诸如断电之类的极端条件测试。
还可以与传统的串口驱动实现进行对照试验。
实现的系统也会有一些特征，设想是通过一些可视化的方式以及定位瓶颈的方法进行研究。
