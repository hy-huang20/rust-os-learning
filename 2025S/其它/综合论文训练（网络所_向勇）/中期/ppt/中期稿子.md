## 1. 研究内容

研究主要是针对Vision Five 2星光二实体开发板上的硬件资源，使用 Rust 语言开发在 AlienOS 中能够使用的异步硬件驱动模块。

预期的研究成果包括：
1) 能在星光二开发板上供 AlienOS 使用的异步串口驱动模块。应该会用到以下的硬件资源。
- GPIO（General-purpose input/output）即通用输入输出端口。
- I2C总线是Philips公司在八十年代初推出的一种串行、半双工的总线
- 相比较于UART, SPI是一个同步的数据总线(Serial Peripheral interface，串行外设接口)
- 通用异步收发传输器（Universal Asynchronous Receiver/Transmitter，通常称为UART）是一种异步收发传输器

2) 能在星光二开发板上使用的闪存异步块设备驱动模块。

## 2. 进展情况与取得成果

### 进展情况

-  对 rCore 以及 Rust Future 进行了一定的学习
- 学习并复现已有的实现
    - rCore-N 基于 rCore ch6 分支并引入了对 N 扩展的支持的 OS
        - 在计算机体系结构中，"N 扩展"（N Extension）通常指的是 RISC-V 架构中的用户级中断处理扩展（N 代表 "User-Level Interrupts"）。这是 RISC-V 指令集架构（ISA）的一个可选扩展，主要用于支持高效的用户态中断处理。
    - 从 rCore-N 中移出了一个异步串口驱动模块，该模块能够供 rCore-N 调用，在 Qemu 环境下运行
    - 使用 Embassy 模式改进上述异步串口驱动，并形成了一个独立于 OS 的 crate

### 目前取得成果

完成了一部分复现工作，目前能够成功运行在 QEMU 模拟器中供 rCore-N 使用的异步串口驱动模块
- 成功编译一个带 N 扩展的 QEMU
- 成功在上述 QEMU 中编译运行 rCore-N
- 通过多开窗口模拟串口与 rCore-N 通信，在启动的 rCore-N 中成功运行 uart_benchmark（异步串口测试程序 ）用户程序
